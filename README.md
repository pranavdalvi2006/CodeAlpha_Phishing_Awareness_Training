# CodeAlpha Phishing Awareness Training

## About the Project
This project is created as part of the CodeAlpha Cyber Security Internship.

It focuses on understanding phishing attacks and educating users about online safety.

## Topics Covered
- Introduction to Phishing
- Email, SMS and Voice Phishing
- Identifying Fake Websites
- Social Engineering Techniques
- Real-world Phishing Examples
- Prevention and Safety Tips
- What to Do After a Phishing Attack
- Interactive Quiz

## Tools Used
- Microsoft PowerPoint
- Cyber Security Awareness Resources

## Project Purpose
The purpose of this project is to improve awareness about phishing attacks and help users stay safe online.
